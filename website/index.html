הגנת המכשיר

בחר קוד גישה. הקוד נשאר בדפדפן ומועבר ישירות לטלפון דרך חיבור ה־USB. הוא לא נשלח לשרת.

4–12 ספרות. הקוד לא יוצג ביומן הפעולות.
חבר קודם את הטלפון ואשר את חלון ניפוי ה־USB. לאחר החיבור הכפתור יופעל.
אין צורך להתקין ADB או כלי נוסף במחשב. האתר משתמש בחיבור USB ישירות דרך הדפדפן הנתמך.

הפעלת אפשרויות למפתחים

  1. פתח בטלפון הגדרות → אודות הטלפון.
  2. מצא מספר Build / מספר גרסה, לפעמים תחת פרטי תוכנה.
  3. לחץ על מספר ה־Build 7 פעמים ואשר קוד נעילה אם נדרש.
  4. חזור להגדרות וחפש אפשרויות למפתחים.
  5. הפעל את האפשרויות למפתחים ואת ניפוי USB.
  6. חבר את הטלפון למחשב ואשר את חלון הרשאת ניפוי ה־USB.
